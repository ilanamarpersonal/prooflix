How it works

From empty servers to a running lakehouse in four steps.

  1. 1

    Install

    Deploy Prooflix to your Kubernetes cluster or a set of VMs with a single command. The installation complies with every major cloud and SaaS provider, and runs just as well fully on-premise. Storage can be local disks or any S3-compatible object store.

  2. 2

    Connect sources

    Point Prooflix at your databases, message queues, file drops and internal APIs using built-in connectors.

  3. 3

    Define pipelines

    Describe how data lands in Bronze, how it is cleaned into Silver and how it is shaped into Gold tables for analytics.

  4. 4

    Run and watch

    Pipelines run their Spark jobs on a schedule or on demand. Track every run from the dashboard.

FAQ

Questions teams ask before leaving a hosted data platform.

What is Prooflix?

Prooflix is a self-hosted data platform for building data pipelines and running a medallion architecture. You install it on your own servers, Kubernetes cluster or cloud account instead of renting a hosted SaaS data platform.

Is Prooflix a data platform on prem?

Yes. Prooflix is a data platform on prem: you install it on your own servers, VMs or bare metal and keep every pipeline, Spark job and table inside your network. The same installation also runs on any cloud account if you need it.

Can I run a medallion architecture on-premise?

Yes. Prooflix implements the Bronze, Silver and Gold medallion layers out of the box. Raw data lands in Bronze, is cleaned and validated into Silver, and is curated into Gold tables for analytics, all inside your own infrastructure.

How do Spark pipelines run in Prooflix?

Each pipeline can run Spark jobs on your cluster. Jobs are scheduled, queued and retried as part of the pipeline run, so there is no separate job server to manage and no compute credits to buy.

Does Prooflix work on AWS, Azure, Google Cloud or fully on-premise?

The installation complies with any cloud or SaaS provider and also runs fully on-premise on VMs or bare metal. Storage can be local disks or any S3-compatible object store.

How does Prooflix avoid SaaS subscription costs?

There is one installation with no per-user licences, no per-workspace fees and no compute markup. You pay for the hardware you already run, so adding users or pipelines does not increase the bill.

Is there vendor lock-in?

No. Prooflix uses plain Spark and open table formats, so your data stays readable by any engine and you can migrate at any time.

Is Prooflix a company?

Not yet. Prooflix is an early-stage project maintained by a small group of contributors. There is no registered company, no sales team and no paid plan. The features on this page describe where the project is heading, and some are still in development.
